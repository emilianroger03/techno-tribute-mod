# Techno Tribute Mod

## What is it?
A Fabric mod for Minecraft 26.2 that brings back the classic string duplication exploit and adds a secret sign-activated power for techno_the_pig__.

## Why am I building this?
Because Technoblade never dies, and string duping was a legendary mechanic that deserves to live on.

## Features
1. **String Duplication** — Break a tripwire hook with connected string, and the string drops as items while staying placed (classic dupe behavior)
2. **Sign of Power** — When player `techno_the_pig__` places a sign with "shall the power come forth", they receive creative flight and /op
